# Keyboard plugin

Tools: `press_key_on_keyboard`, `write_with_keyboard`.

- Use known standard keyboard shortcuts directly; only look up a shortcut when genuinely uncertain.
- `press_key_on_keyboard` takes combined keys as `key1:key2:key3`, e.g. `ctrl:c`, `win`.
- To open a Windows application, normally use: `win` → `write_with_keyboard` the app name → `enter`.
- Don't use the keyboard when a safer or more direct available tool can do the same thing (e.g. use the files plugin to write a file instead of typing it out with the keyboard).
